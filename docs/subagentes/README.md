# Subagentes do Claude Code

Subagentes especializados que o Claude Code carrega automaticamente ao abrir este repositório.

| Subagente | Para que serve |
|---|---|
| `typescript-pro` | Tipagem e padrões avançados de TypeScript |
| `react-specialist` | Componentes, hooks e desempenho no React |
| `node-specialist` | Servidor Node.js e Express |
| `sql-pro` | Consultas e modelagem do banco (Drizzle/MySQL) |
| `fullstack-developer` | Funcionalidades que atravessam cliente e servidor |
| `code-reviewer` | Revisão de código antes do merge |
| `debugger` | Investigação de bugs e causa raiz |
| `security-auditor` | Auditoria de segurança (somente leitura) |
| `test-automator` | Criação e manutenção de testes com Vitest |
| `llm-architect` | Integração com modelos de linguagem (Ollama, FreeLLMAPI) |
