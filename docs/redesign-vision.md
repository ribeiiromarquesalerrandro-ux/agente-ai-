# Direção visual — Agente AI Local

O redesenho parte do conceito **Neon Command Studio**. Em vez de uma única superfície de terminal, a aplicação passa a se comportar como um estúdio de comando visual: superfícies curvas de vidro escuro, luzes de ciano, violeta e coral, grandes zonas tipográficas e sinais operacionais em camadas.

| Princípio | Aplicação |
|---|---|
| Contraste dramático | Fundo quase preto, gradientes coloridos pontuais e tipografia de alto impacto. |
| Navegação expressiva | Barra lateral elevada, cartões de navegação e indicadores de estado mais legíveis. |
| Interface em camadas | Superfícies translúcidas, bordas luminosas e sombras profundas para separar áreas funcionais. |
| Ação evidente | Botões principais com preenchimento de gradiente, estados de foco claros e microinterações curtas. |
| Responsividade real | Elementos reorganizados em coluna no celular, mantendo as ações críticas acessíveis. |

O objetivo é tornar o produto mais memorável e visualmente ativo, sem alterar permissões, planos, memória, ferramentas, chat ou integrações existentes.
